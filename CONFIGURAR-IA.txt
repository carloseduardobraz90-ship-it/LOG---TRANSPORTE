CONFIGURAÇÃO DA IA GEMINI

1. Abra script.js no VS Code.
2. Busque ADD CHAVE API AQUI.
3. Substitua o texto pela chave do Google AI Studio.
4. Salve e publique os arquivos.
5. Na aba Roteirizador, use Buscar com IA nos endereços pendentes.

ATENÇÃO: a chave no JavaScript de um site GitHub Pages é PUBLICAMENTE VISÍVEL para qualquer visitante. O uso pode consumir sua cota e gerar custos conforme seu plano. Para manter a chave privada, use um backend.

A IA sugere buscas, mas não garante endereços corretos. Confirme o ponto antes de salvar.
