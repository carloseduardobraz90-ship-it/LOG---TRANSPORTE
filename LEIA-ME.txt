PHARMAINox Dashboard — 4 arquivos de veículos

IDENTIFICAÇÃO DOS VEÍCULOS
- O nome do arquivo NÃO é utilizado para identificar o veículo.
- A identificação vem dos dados internos da planilha/CSV.
- FVB2C57 usa: Jornada/KM + Abastecimento.
- FCL9986 usa: Jornada/KM + Abastecimento.
- O sistema confere a PLACA/VEICULO dentro do arquivo antes de carregar.

CORREÇÃO PRINCIPAL
- A busca das colunas agora prioriza correspondência exata antes de correspondência parcial.
- Isso evita confundir o cabeçalho "NA PHARMAINNOX ESSE VEICULO ESTA:" com a coluna PLACA.

JORNADA / KM
- Usa os registros SAINDO e CHEGANDO.
- KM inicial = SAINDO do dia.
- KM final = CHEGANDO do dia.
- KM rodado = KM final - KM inicial.

ABASTECIMENTO
- Usa exclusivamente os arquivos de abastecimento para valor, litros, preço/L e KM do abastecimento.
- Preço: 2025 = R$ 6,49/L; 2026 = R$ 7,49/L.


V3
- Os 4 arquivos dos veículos podem ser adicionados juntos em um único seletor.
- O sistema identifica veículo e tipo pelo conteúdo interno; o nome do arquivo não é usado.
- Os gráficos de tempo possuem seletor de Mês, Semana ou Ano.
- Os gráficos exibem rótulos de dados diretamente na tela.


MAPA / ROTAS
- O mapa da rota usa Google Maps JavaScript API.
- A geocodificação dos endereços usa o serviço Geocoding da Google Maps JavaScript API.
- A rota viária e a otimização das paradas usam a biblioteca Routes da Google Maps JavaScript API.
- As coordenadas encontradas são armazenadas no localStorage do navegador para evitar nova geocodificação a cada abertura.
- No script.js existe apenas um campo para a chave: GOOGLE_MAPS_API_KEY = 'ADD SUA CHAVE AQUI'.
- Para funcionar, a chave deve ter permissão para Maps JavaScript API, Geocoding API e Routes API, conforme a configuração do projeto Google Cloud.


SOLUÇÃO DE PROBLEMAS — GOOGLE MAPS
- Se o console mostrar ApiNotActivatedMapError, ative a Maps JavaScript API no projeto Google Cloud associado à chave.
- A chave também deve ter faturamento habilitado e autorização para as APIs usadas pelo projeto.
- Para publicação no GitHub Pages, restrinja a chave por HTTP referrer ao domínio do site e deixe somente as APIs necessárias autorizadas.
- O carregador do script.js usa o Dynamic Library Import oficial do Google, evitando o erro "google.maps.importLibrary is not a function" causado por carregar a API sem o bootstrap adequado.
